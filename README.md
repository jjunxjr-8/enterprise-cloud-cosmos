# COSMOS CLOUD Admin Manual

## How to change data on CLOUD
1. change information on official google sheets

2. copy and paste the entire contents from cell R2

3. delete all contents of data.json of this repo and replace it with the content you copied from step.2

4. commit changes
<br>
<br>
<br>

## Possible breaks and solutions
there is a possibility that the data does not connect to the website which would happen when the student with the appscript of the spreadsheet connected to their account has left the school. In order to solve this, <b>1 person </b> should open the appscript of the spreadsheet and enter the contents of extract.gs (found in this repo), then go to 'triggers' on the sidemenu and leave all settings as it is <b> apart from </b> the last one which should be set to onEdit.<br>
<b>IT IS REALLY IMPORTANT THIS IS DONE ON ONE PERSON'S ACCOUNT </b>

## In case the website breaks
there is a read only back up version of the exact repo in the COSMOS github organisation account.<br>
you should already have access to it<br>
if you don't, please contact the current chair of COSMOS
